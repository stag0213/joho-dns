# DNS名前解決・学習シミュレータ（高校情報Ⅰ 教材）

## 高等学校の「情報Ⅰ」（情報社会の課題とネットワーク・データの活用）における、DNS（Domain Name System）と名前解決の仕組みを視覚的・体験的に学ぶためのWeb教材アプリケーションです。

### 🌟 アプリの概要

ドメイン名（例: www.mext.go.jp）からIPアドレスを取得する「名前解決」のプロセスを、アニメーションとパケットログで分かりやすく可視化します。

テキストでの説明だけでは理解しにくい 「再帰的問い合わせ」 と 「反復的問い合わせ」、「DNSキャッシュの役割」 を直感的に理解できるように設計されています。

### 🚀 主な機能

1. 名前解決ビジュアルシミュレータ

任意のドメイン入力: 事前登録された主要サイトに加え、生徒自身が調べたいWebサイト（例: google.com, wikipedia.org など）を自由に入力可能。

分散管理の階層アニメーション:

クライアント PC (スタブリゾルバ)

キャッシュ DNS サーバ (フルリゾルバ)

ルート DNS サーバ (.)

TLD DNS サーバ (.jp, .com など)

権威 DNS サーバ (自ドメイン)

各ノード間の問い合わせ順序と応答がリアルタイムに点灯表示されます。

DNSキャッシュ体験: キャッシュの有無による検索ルート・速度の違い（キャッシュヒット時の高速応答）をON/OFFトグルで比較できます。

パケット通信ログ: ターミナル風ログエリアで通信データ（リクエスト/レスポンス）の詳細を確認可能です。

2. DNS検索コマンド体験 (nslookup)

実際のネットワーク管理コマンド nslookup を模したインターフェース。

代表的なDNSレコードタイプを選択して照会結果を確認可能：

A レコード (IPv4 アドレス)

AAAA レコード (IPv6 アドレス)

MX レコード (メールサーバ)

NS レコード (ネームサーバ)

CNAME レコード (別名)

3. 理解度確認クイズ

教科書レベルの4択クイズ（全4問）を収録。

回答後、すぐに正誤判定と丁寧な解説を表示。

クラス内での授業の振り返りや小テストとして利用可能です。

### 🎓 授業での活用例（指導案アイデア）

導入 (5分):

「Webブラウザに www.mext.go.jp と入力したとき、裏側で何が起きているか？」を問いかける。

体験・検証 (20分):

生徒各自の端末で本アプリを開く。

自分の好きなWebサイトのURLを入力してシミュレータを実行。

問い合わせが「ルート → TLD → 権威サーバ」の順に行われる階層構造を確認する。

「キャッシュを使用」にチェックを入れて再実行し、問い合わせ時間の短縮とルートの変化を観察・考察させる。

発展学習 (10分):

「コマンド体験」タブに切り替え、AレコードやMXレコードなど、用途に応じた情報の違いを調べる。

まとめ・評価 (10分):

「確認クイズ」を実施し、自己評価・知識の定着を図る。

### 🛠️ 動作環境・技術スタック

本アプリは単一のHTMLファイル（シングルファイルアプリ）として動作するため、サーバや複雑なビルド環境の構築は不要です。GIGAスクール構想のChromebook、iPad、Windows端末の標準ブラウザでそのまま利用できます。

HTML5 / JavaScript (ES6+)

Tailwind CSS (UIスタイリング / CDN使用)

Lucide Icons (アイコン表示 / CDN使用)

### 💻 使い方・実行方法

リポジトリ内の index.html をダウンロードします。

ダウンロードした index.html をダブルクリック（またはWebブラウザへドラッグ＆ドロップ）して開きます。

インターネット接続環境（Tailwind CSSおよびアイコン読み込み用）があれば、特別な設定なしですぐに動作します。
